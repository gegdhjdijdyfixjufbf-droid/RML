# RML

RML is a markup language I'm developing in Python, with an embedded scripting language called SJ.

## Features
- Titles and text
- Clickable links
- Images
- Embedded SJ scripts
- Tkinter-based renderer

## Requirements
- Python 3

## Run RML

1. Download or clone this repository.
2. Put your RML files and images in the project folder.
3. Run:

```bash
python rml_renderer.py
```

The renderer opens `index.rml` by default.

RML is an early-stage project. Feedback and suggestions are welcome!
